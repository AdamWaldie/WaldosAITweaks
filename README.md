# Waldos AI Tweaks

Mission-native AI behaviour, coordination, vehicle, aircraft and skill systems for Arma 3.

This repository is being extracted from the AI development branch of [Waldos Mission Pack](https://github.com/AdamWaldie/WaldosMissionPack). Its purpose is to keep optional AI control independent from WMP features such as Dynamic AA, Dynamic AO, logistics, economy and mission flow.

The initial extraction is developed through a pull request. WMP remains the source of truth until that pull request is accepted and its standalone installation and migration checks pass.
